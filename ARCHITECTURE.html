Architecture artifact · 23 August 2026 · Mac-first

Handy

A private personal input shelf that makes a curated library of kaomojis, emoji, and snippets available in under a second, with a portable format that can grow from Mac to iPhone without a service.

Priority zero

The library is private by construction. No network client, account, analytics, clipboard monitoring, or keystroke logging exists in v1. The hard acceptance bar is a packet-capture-free executable review and an automated test suite that touches only a temporary local library.

Diagnosis

macOS has a capable Emoji & Symbols viewer, Maccy retains clipboard history, and text replacements sync across Apple devices. None is a fast, searchable, intentional library for personal expressive text. Existing inspiration offers a single-purpose Mac palette or a terminal-only copy picker.

Core idea

[global shortcut] → [searchable shelf] → [copy selected text]
                                    ↓
                         [local library.json]

Copy is the universal action. Direct paste is not a v1 promise because application focus and accessibility permission make it inherently conditional.

Options assessed

Fork kaomoji-pickerRejected: terminal UX is useful, but not an instant universal shelf.
Build on MaccyRejected: clipboard history and intentional snippets are distinct privacy and interaction models.
Local JSON schemaChosen: inspectable, portable, versionable, and offline.

Risks and mitigation

RiskSeverityMitigation
Global shortcut collisionMediumUse a conservative default and make it configurable next.
Clipboard lossHighOnly copy in v1. No background observation or automatic restoration.
iOS keyboard restrictionMediumKeep iPhone out of v1 and design it to work offline without Full Access.

Vocabulary and ADR

Library means the JSON collection. Item is one pasteable text value. Shelf is the Mac search surface. ADR-001: copy, rather than direct paste, is the universal v1 completion action.

Explicitly not in v1

Clipboard history, server sync, arbitrary app automation, iPhone keyboard, AI generation, and accounts. Build the iPhone companion after the Mac library format proves stable and export/import is tested.

Public demo amendment

The repository includes a dependency-free GitHub Pages demo in docs/index.html. It is a keyboard-accessible model of the copy-first shelf, not a web replacement for the native app. Deployment is manual so the public surface is verified before publication.
