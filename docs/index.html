Live demo. Nothing is uploaded or saved.

One shelf, four kinds of useful text.

Handy is intentional storage. It is not a clipboard-history replacement.

KaomojisSearch a feeling like confused, not an exact character string.
EmojiKeep the symbols you reach for, labelled in your own language.
SnippetsReuse a reply, address, sign-off, or command.

Tags are the retrieval layer.

Titles name the item. Tags capture the context you remember later.

confused → Shrug
celebrate → Sparkles
reply → Thank you

Maccy remembers what you copied recently. Handy remembers what you meant to keep.

Private by construction.

No account, analytics, network requests, clipboard-history collection, or background monitoring.

From shortcut to clipboard.

⌥⌘K → search local library → copy selected text

Copy is the reliable cross-app action.
